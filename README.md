# ⚡ Elektron - Aplikacja dla Elektryka

Profesjonalna aplikacja webowa (PWA) do zarządzania firmą elektryczną.

## 🚀 Funkcje

### ✅ Zarządzanie Klientami
- Dodawanie, edycja i usuwanie klientów
- Pełne dane kontaktowe (telefon, email, adres)
- Notatki o klientach

### ✅ Zarządzanie Zleceniami
- Tworzenie zleceń z przypisaniem do klienta
- Statusy: Nowe, W trakcie, Zakończone, Anulowane
- Filtry i wyszukiwanie
- Harmonogram (daty rozpoczęcia/zakończenia)
- Szacowane godziny pracy

### ✅ Rejestracja Godzin Pracy
- Zapisywanie godzin pracy dla każdego zlecenia
- Historia wpisów z datami i notatkami
- Podsumowanie łącznej liczby godzin
- Tabela w stylu Excel

### ✅ Dashboard
- Przegląd statystyk: klienci, zlecenia, godziny
- Aktywne i zakończone projekty
- Godziny pracy w bieżącym miesiącu

### 📱 Funkcje mobilne (PWA)
- **Instalacja jak aplikacja natywna** na Android i Windows
- **Praca offline** - przeglądanie danych bez internetu
- **Automatyczna synchronizacja** między urządzeniami
- **Powiadomienia push** o nadchodzących zleceniach
- **Responsywny design** - działa na telefonach i tabletach

## 🛠️ Technologie

**Backend:**
- FastAPI (Python)
- MongoDB
- 15+ RESTful API endpoints

**Frontend:**
- React 19
- Tailwind CSS
- Shadcn/UI Components
- Service Worker dla PWA
- Push Notifications API

## 🔄 Synchronizacja

Wszystkie dane są przechowywane w chmurze i automatycznie synchronizowane między urządzeniami:
- ✅ Telefon ↔️ Komputer
- ✅ Natychmiastowa synchronizacja online
- ✅ Automatyczna synchronizacja po powrocie do zasięgu

## 🔔 Powiadomienia

Otrzymuj przypomnienia o:
- Nadchodzących zleceniach (dziś/jutro)
- Sprawdzanie co godzinę
- Działają nawet gdy aplikacja jest zamknięta
