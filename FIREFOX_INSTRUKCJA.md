# 🦊 FIREFOX - Instrukcja krok po kroku

## ✅ KROK 1: Pobierz Firefox (2 minuty)

### Na komputerze:
1. Otwórz Chrome (tak, jeszcze raz 😊)
2. Wejdź na: **https://www.mozilla.org/pl/firefox/new/**
3. Kliknij duży niebieski przycisk **"Pobierz Firefox"**
4. Poczekaj aż się pobierze (ok. 50 MB)

---

## ✅ KROK 2: Zainstaluj Firefox

### Windows:
1. Otwórz pobrany plik **Firefox Installer.exe**
2. Kliknij **"Zainstaluj"**
3. Poczekaj 1-2 minuty
4. Firefox otworzy się automatycznie

### Mac:
1. Otwórz pobrany plik **Firefox.dmg**
2. Przeciągnij ikonę Firefox do folderu Aplikacje
3. Otwórz Firefox z Launchpad

---

## ✅ KROK 3: Otwórz aplikację w Firefox

1. W pasku adresu Firefox wpisz:
```
https://elektron-smart.preview.emergentagent.com
```

2. Naciśnij **Enter**

3. **Aplikacja powinna działać bez problemu!** 🎉
   - ✅ DevTools NIE będą się otwierać
   - ✅ Wszystko działa normalnie

---

## 📱 KROK 4 (OPCJONALNIE): Zainstaluj jako PWA w Firefox

Aby mieć ikonę na pulpicie jak normalną aplikację:

1. Gdy aplikacja się załaduje, kliknij **☰** (menu) w prawym górnym rogu
2. Wybierz **"Zainstaluj"** lub **"Zainstaluj aplikację"**
3. Kliknij **"Zainstaluj"**
4. Aplikacja pojawi się jako ikona na pulpicie i w menu Start

---

## 🔖 KROK 5: Dodaj zakładkę (OPCJONALNIE)

Aby łatwo wracać do aplikacji:

1. Kliknij **⭐** (gwiazdka) w pasku adresu
2. Wpisz nazwę: **"Elektron"**
3. Kliknij **"Gotowe"**

Teraz będziesz miał zakładkę na pasku zakładek.

---

## 📱 NA TELEFONIE (Android):

### KROK 1: Pobierz Firefox
1. Otwórz **Play Store**
2. Szukaj: **"Firefox"**
3. Pobierz **"Firefox Browser"** (pomarańczowa lisica)
4. Zainstaluj

### KROK 2: Otwórz aplikację
1. Otwórz Firefox
2. W pasku adresu wpisz:
```
https://elektron-smart.preview.emergentagent.com
```
3. **Działa!** 🎉

### KROK 3: Dodaj do ekranu głównego
1. Kliknij **☰** (menu) w prawym górnym rogu
2. Wybierz **"Zainstaluj"** lub **"Dodaj do ekranu głównego"**
3. Wpisz nazwę: **"Elektron"**
4. Kliknij **"Dodaj"**
5. Ikona pojawi się na ekranie głównym

## ❓ Pytania i odpowiedzi:

### Czy muszę usunąć Chrome?
❌ NIE! Możesz mieć oba. Firefox będzie używany tylko do aplikacji Elektron.

### Czy Firefox jest bezpieczny?
✅ TAK! Firefox jest jedną z najbardziej bezpiecznych przeglądarek.

### Czy aplikacja będzie działać tak samo?
✅ TAK! Wszystkie funkcje będą działać identycznie jak w Chrome.

### Czy mogę wrócić do Chrome później?
✅ TAK! Jak naprawisz Chrome, możesz wrócić. Firefox zostanie jako backup.
